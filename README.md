# 🔥 SmartCrackers

SmartCrackers is a web-based cracker shopping system developed using Python Flask and MariaDB.

## 🚀 Features

- 👤 User Registration and Login
- 🛍️ Product Listing
- 🔍 Product Search
- 🏷️ Category and Price Filters
- 🛒 Shopping Cart
- 📦 Checkout and Order Management
- 🤖 AI-based Product Recommendation
- 💬 AI Chatbot
- ❤️ Wishlist
- ⭐ Product Reviews
- 👨‍💼 Admin Management

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- MariaDB / MySQL
- PyMySQL
- AI / Machine Learning
